# Сайт репетитора по обществознанию

Коммерческий проект лендинга для частного преподавателя обществознания, специализирующегося на подготовке школьников к ОГЭ и ЕГЭ.

Сайт предоставляет информацию об образовательных услугах, формате обучения, отзывах учеников и содержит формы обратной связи для записи на консультацию. Особое внимание было уделено адаптивности интерфейса, удобству пользователей и конверсии заявок.

## 📌 Информация о проекте

- **Тип проекта:** Коммерческий
- **Период разработки:** Сентябрь 2025
- **Роль:** Frontend Developer
- **Команда:** Designer, Backend Developer
- **Основные технологии:** JavaScript, jQuery

## 👨‍💻 Выполненные задачи

- Разработал адаптивный лендинг для десктопных и мобильных устройств;
- Реализовал формы обратной связи и записи на консультацию;
- Разработал интерактивный FAQ и модальные окна;
- Настроил маски ввода телефонных номеров с использованием IMask.js;
- Оптимизировал пользовательский интерфейс и взаимодействие с сайтом;
- Обеспечил корректную работу проекта на различных устройствах.

## 📈 Результаты

- Улучшен пользовательский опыт на мобильных и десктопных устройствах;
- Упрощён процесс отправки заявок на консультацию;
- Повышена вовлечённость пользователей благодаря понятной структуре и интерактивным элементам.

## 🛠️ Технологический стек

`HTML` · `CSS` · `JavaScript` · `jQuery` · `IMask.js`
