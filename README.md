# Social Studies Tutor Landing Page

A commercial landing page developed for a private social studies tutor specializing in OGE and EGE exam preparation.

The website presents educational services, student reviews, frequently asked questions, and includes lead generation forms for consultation requests. The project was designed with a strong focus on accessibility, responsive design, and conversion optimization.

## 📌 Project Overview

- **Project Type:** Commercial
- **Development Period:** September 2025
- **Team:** Designer, Backend Developer
- **Core Technologies:** JavaScript, jQuery

## 👨‍💻 Responsibilities

- Developed a fully responsive landing page;
- Implemented adaptive layouts for desktop and mobile devices;
- Created interactive FAQ and modal components;
- Developed lead generation and feedback forms;
- Integrated phone number masking with IMask.js;
- Optimized user experience and page performance.

## 📈 Results

- Improved accessibility across all device types;
- Streamlined the consultation request process;
- Increased user engagement through clear navigation and interactive sections.

## 🛠️ Technology Stack

`HTML` · `CSS` · `JavaScript` · `jQuery` · `IMask.js`
