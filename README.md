# Social Studies Tutor Landing Page

</div>

A commercial landing page developed for a private social studies tutor specializing in preparing school students for the OGE and EGE exams.

The website presents educational services, the lesson format, student reviews, and answers to frequently asked questions, and includes feedback and consultation request forms. The project focuses on accessibility, responsive design, usability, and conversion optimization.

## ✨ Features

- Information about educational services and the lesson format
- Student reviews
- Interactive FAQ and modal windows
- Feedback and consultation request forms
- Responsive interface for desktop and mobile devices

## 📌 Project Overview

- **Project Type:** Commercial
- **Development Period:** September 2025
- **Role:** Frontend Developer
- **Team:** Designer, Backend Developer
- **Core Technologies:** JavaScript, jQuery

## 👨‍💻 Responsibilities

- Developed a responsive landing page for desktop and mobile devices
- Created an interactive FAQ and modal windows
- Developed lead generation and feedback forms for consultation requests
- Integrated phone number masking using IMask.js
- Optimized the interface, user experience, and page performance
- Ensured the website works correctly across different devices

## 📈 Results

- Improved accessibility and user experience across all device types
- Streamlined the consultation request process
- Increased visitor engagement through clear structure, navigation, and interactive elements

## 🛠️ Technologies

- **HTML**
- **CSS**
- **JavaScript**
- **jQuery**
- **IMask.js**
